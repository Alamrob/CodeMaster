# Demos: huellas de IA reales

Esta carpeta contiene archivos de ejemplo con huellas de IA detectables, para
probar la plataforma. Regeneralos con:

```
python demos/make_traces.py
python demos/make_traces_extra.py
```

## Que encontrara CodeMaster

| Archivo | Huellas detectadas |
| --- | --- |
| `app.py` | comentario `generated by claude`, docstring, glifo invisible U+200B |
| `notas.md` | narracion ("Note that", "Feel free to", "Keep in mind"), modelo `chatgpt` |
| `foto.jpg` | metadatos EXIF |
| `anim.gif` | extension Comment de GIF |
| `libro.epub` | narracion + glifo invisible en XHTML |
| `propuesta.docx` | autor `GPT-4o` / `claude` en core.xml |
| `doc.pdf` | `/Author`, `/Creator`, `/Producer` de IA |

Ejecuta el escaneo:

```
codemaster scan demos/ai-traces
```

o analiza la carpeta desde el dashboard web (`codemaster-web`) o la app de
escritorio (`codemaster-gui`).
